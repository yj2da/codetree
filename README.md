# 🌲 CodeTree Algorithm & Problem Solving Archive

> **코드트리(CodeTree) 커리큘럼 기반 알고리즘, 자료구조 및 코딩테스트 문제 풀이 기록 아카이브**

---

## 📌 Topics Covered

- **기본기 & 시뮬레이션**: 완전탐색(Brute Force), 격자 시뮬레이션, 구현
- **자료구조**: 스택, 큐, 덱, 해시맵(HashMap), 힙(Priority Queue)
- **탐색 알고리즘**: DFS, BFS, 이진 탐색(Binary Search), 투 포인터(Two Pointer)
- **동적 계획법 (Dynamic Programming)**: 1차원/2차원 DP, 배낭 문제(Knapsack)
- **그래프 알고리즘**: 다익스트라(Dijkstra), 유니온-파인드(Disjoint Set)

---

## 📂 Directory Structure

```
├── Basic/                 # 기초 문법 및 기본 구현 문제
├── Novice_Mid/            # 시뮬레이션 및 완전탐색
├── Intermediate_Low/      # DFS/BFS 및 기본 DP
└── Intermediate_Mid/      # 고급 자료구조 및 심화 알고리즘
```
